# CITES-Protected African Wood: Identification for Officers (course)

Open `index.html` (published at `.../CITES-Timber-ID/course/`). English only. Includes the Mr Minfin video (`video/Minfin_CITES_Timber_Africa_EN.mp4`, 2:40) with chapter buttons, knowledge checks, 2 scenarios, a 10-question final assessment (pass mark 7) and a dated certificate.

## Collecting results (Google Form)
1. Create a Google Form with short-answer questions: Name, Trainer, Score, Passed, Date (optional: Best score, Out of).
2. In the Form menu choose "Get pre-filled link", fill each question with a sample, and copy the link. It contains `entry.NNN=` ids.
3. Put the Form address (replace `viewform` with `formResponse`) in `config.js` as `formUrl`, and the entry ids under `fields`.
4. Link the Form's Responses to a Google Sheet and share it with the trainers.

Without a Form, learners get a "Copy my result" button (or email if `mailto` is set in `config.js`).

## Keeping it current
CITES listings change at each Conference of the Parties. Review lessons 2, 4 and 5 and the final quiz after each CoP.
