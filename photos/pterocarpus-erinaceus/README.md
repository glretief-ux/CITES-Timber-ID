# 10x photos — Pterocarpus erinaceus

Put **real** 10x end-grain photographs of verified reference specimens here.

File naming: `pterocarpus-erinaceus_<xylarium-or-agency>_<specimen-no>_<n>.jpg`
(e.g. `pterocarpus-erinaceus_MADw_12345_1.jpg`)

For every photo add one row to [`../manifest.csv`](../manifest.csv).

## What to photograph
1. Transverse (end-grain) surface, cut clean with a sharp blade, **10x**, field ~5-7 mm wide, with scale bar.
2. Same spot wetted (water) — improves contrast of parenchyma.
3. Tangential face at 10x if ripple marks are expected (expected here: **yes**).
4. Optional: UV (365 nm) fluorescence of the end grain.

## Features the photo must show
Red-purple 'rosewood' with semi-ring-porous tendency, fine wavy parenchyma bands and clear ripple marks. Top species in illegal West African hongmu log trade (round logs, squared beams). No annotation - all parts covered.
