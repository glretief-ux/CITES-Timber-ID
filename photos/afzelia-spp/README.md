# 10x photos — Afzelia spp. (African populations)

Put **real** 10x end-grain photographs of verified reference specimens here.

File naming: `afzelia-spp_<xylarium-or-agency>_<specimen-no>_<n>.jpg`
(e.g. `afzelia-spp_MADw_12345_1.jpg`)

For every photo add one row to [`../manifest.csv`](../manifest.csv).

## What to photograph
1. Transverse (end-grain) surface, cut clean with a sharp blade, **10x**, field ~5-7 mm wide, with scale bar.
2. Same spot wetted (water) — improves contrast of parenchyma.
3. Tangential face at 10x if ripple marks are expected (expected here: **variable**).
4. Optional: UV (365 nm) fluorescence of the end grain.

## Features the photo must show
Large, few pores with YELLOWISH-WHITE deposits + lozenge/confluent parenchyma + orange-brown heartwood. Proposal at CoP20 to remove Central African A. bipindensis was rejected - still listed.
