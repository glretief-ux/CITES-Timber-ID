# 10x photos — Guibourtia demeusei, G. pellegriniana, G. tessmannii

Put **real** 10x end-grain photographs of verified reference specimens here.

File naming: `guibourtia-bubinga_<xylarium-or-agency>_<specimen-no>_<n>.jpg`
(e.g. `guibourtia-bubinga_MADw_12345_1.jpg`)

For every photo add one row to [`../manifest.csv`](../manifest.csv).

## What to photograph
1. Transverse (end-grain) surface, cut clean with a sharp blade, **10x**, field ~5-7 mm wide, with scale bar.
2. Same spot wetted (water) — improves contrast of parenchyma.
3. Tangential face at 10x if ripple marks are expected (expected here: **no**).
4. Optional: UV (365 nm) fluorescence of the end grain.

## Features the photo must show
Pinkish-red, purple-veined heartwood; medium pores often gum-filled; aliform-confluent parenchyma; NO ripple marks (helps separate from Dalbergia and Pterocarpus). Three listed species cannot be separated from each other or from unlisted Guibourtia (e.g. G. ehie - ovangkol) by hand lens.
