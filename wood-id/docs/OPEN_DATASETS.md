# Open and requestable wood image datasets (checked 2026-10-14)

Only what was read on the dataset pages. Download links and licences must be re-checked before use.

| Dataset | What it holds | Fit for African CITES timber | Access / licence |
|---|---|---|---|
| GOIMAI Phase I, [Zenodo 11092208](https://zenodo.org/records/11092208) | Phone + 24x lens end-grain photos, 37 archives | Pericopsis elata (558 MB) and Prunus africana (257 MB, already held) | Open, CC BY-SA 4.0 |
| XyloMaMi-Bench, [Zenodo 20350819](https://zenodo.org/records/20350819) | 36,742 end-grain JPEGs, 100 tropical species, Dino-Lite Edge AM4115ZT, 1280x1024 (same camera class as ours; page states 50x) | Page example folder is Afzelia_africana and it overlaps with a Congo reference set. African CITES coverage not confirmed: read `metadata/species_catalogue.csv` (open file) | Images restricted: request access on Zenodo (name, institution, intended use; reviewed in 5 working days), Data Use Agreement, CC BY-NC 4.0 on open files |
| CITES-28, [Frontiers 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11239398/) | 9,437 XyloTron images of 279 specimens: 14 CITES species (Dalbergia, Pterocarpus incl. P. angolensis, Guibourtia demeusei and tessmannii) + 14 look-alikes (incl. Guibourtia ehie, Baphia nitida, Bobgunnia madagascariensis) | Very good match for the listed/look-alike question | Not public: ask the corresponding author (Tuo He, tuohe@caf.ac.cn) |
| SmartWoodID, [Tervuren](https://hdl.handle.net/20.500.12624/SmartWoodID_first_edition) | 4,740 sanded end-grain flatbed scans (2400 dpi) of 1,190 Congo Basin taxa; names Afzelia bipindensis, Khaya anthotheca, Pterocarpus soyauxii, Pericopsis elata | Best African coverage, but a scanner, not a microscope: different look | Viewer (IIIF), no bulk download described; licence not stated: ask the museum |
| Wood Species Dataset, [Zenodo 2545611](https://zenodo.org/records/2545611) | 8,544 macroscopic images, numbered categories | Species not named on the page: unknown | CC BY 4.0, 47.5 MB |

Different camera, lighting and scale from our Dino-Lite photos: keep each source labelled and never mix them without a camera label.

## Image libraries checked for reuse terms (2026-10-14)

| [InsideWood](https://insidewood.lib.ncsu.edu/citingus) | Copies for nonprofit own/organisation use with acknowledgement; no redistribution for gain; large-scale processing or redistribution needs written permission; each image copyright belongs to its photographer and institution | Mostly microscopic sections; ask NC State before any bulk use |
| [DELTA wood ID, Thuenen Institute](https://www.delta-intkey.com/wood/en/contacts.htm) | Images not to be distributed further without prior permission of the authors | Ask the authors |
| [Tervuren Xylarium on GBIF](https://www.gbif.org/dataset/b0cb000d-9381-4881-98d9-1594acf59c89) | 10,189 specimen records; the page shows no images or licence | Records only as far as checked; the museum holds the physical collection |

Finding: no large openly licensed image set of African CITES timbers was found beyond GOIMAI (two species).
The realistic route is access to physical xylarium samples that can be photographed with our own Dino-Lite.
